# Proposed specification amendments

> **Status · Awaiting maintainer decision, 2026-11-27.** None of these amendments has been applied to the [PRD](PRD.md), [UI specification](UI_SPECIFICATION.md) or [design system](DESIGN_SYSTEM.md). They record contradictions between those approved specifications, the technical evidence and the proposed [architecture](ARCHITECTURE.md). The architecture and [implementation plan](IMPLEMENTATION_PLAN.md) assume the **recommended** option for each item; if the maintainer chooses otherwise, the listed modules must be revised before implementation.
